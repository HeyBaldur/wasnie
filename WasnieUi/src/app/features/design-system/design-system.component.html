Icons

File formats are brand marks, not glyphs. Excel and PDF have their own raster icons in public/icons/; their colour is part of their meaning, so they cannot be a currentColor path like the rest of the set. Any button that produces one of those files uses these — never download, file or file-text.

file-excel file-pdf

Everything else is a stroked SVG that inherits the current text colour. A few of the ones that get reached for most:

Export menu

One button, one choice. When a screen offers the same document in more than one format they go in a menu behind a single Export — two side-by-side buttons make one document look like two different actions.
